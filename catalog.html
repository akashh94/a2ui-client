These are the components this client knows how to draw — the renderer half of the A2UI contract. It registered one renderer per component name in the agent's catalog.json.

Everything below is rendered locally from static payloads: no agent, no network call, nothing to flake. Each panel shows the rendered result next to the A2UI JSON that produced it, and that JSON is the same shape the agent sends over A2A — a createSurface message followed by updateComponents.
